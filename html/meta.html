HTML5 Meta Tags Demonstration

This page demonstrates commonly used HTML5 meta tags related to responsive design, SEO, security, social media and web applications.

Responsive Design

The viewport meta tag allows this webpage to adapt to different screen sizes such as mobile phones, tablets and desktop computers.

SEO Metadata

The description, robots and canonical URL provide information that can help search engines understand and handle the webpage.

Social Media Metadata

Open Graph and Twitter/X Card metadata can control the information displayed when the webpage is shared on supported social platforms.

Important Note for Students

  • Meta tags are generally placed inside the <head> section.
  • Most meta tags do not produce visible content directly.
  • The viewport tag is important for responsive design.
  • Description and robots are useful SEO-related metadata.
  • Open Graph tags are used for social sharing previews.
  • Canonical URL is an SEO concept but is implemented using <link>.
  • Some tags, such as X-UA-Compatible, are mainly legacy concepts.
